# Examples
Example projects

README

1)    #[JavaFX Snake Game with Score Database]# Group project using JavaFX in 2018, developed an arcade-style Snake game. You contributed to the UI and implemented a database to track scores. I have attached all our final deliverables. You can read the text file and run setup to play it.
2)    #[Prostate CT Segmentation Using UNet (Colab Notebook)]# A graduate-level machine learning assignment demonstrating the use of a UNet architecture to segment prostate regions in CT scans using Python in Google Colab. It will run a UNet model that learns to segment prostate regions from CT scans. You will have to download the data folder on your own Google Drive account to run the notebook. You will also need to change the directory location at the top of the notebook to match your directory structure, and enable Colab’s GPU hardware accelerator in the Change Runtime Type menu.
3)    #[C# Job and Interrupt Simulation]# An early C# project from a data structures course simulating job arrival and runtime scheduling with user input. Includes test cases and a compiled executable.
